# Lessons (long form)

Detailed lessons learned, one topic per file, named `YYYY-MM-DD-slug.md`. Every file here must
have a matching bullet in `../lessons.md`. Rules are in `AGENTS.md`.

## Template

```markdown
---
title: The rule, in one line
date: YYYY-MM-DD
tags: [area, e.g. windows, cli, lessons-data]
source: bug fix / review / run log / PR link
---

# Title

## Context
What happened: symptom, where, how it was found.

## Root cause

## Lesson
The rule to follow from now on, stated so an agent can apply it.

## Example
Code or commands showing the wrong and the right way.
```
